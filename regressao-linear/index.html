Como funciona

  1. A reta é y = w·x + b. Começa com w = 0.
  2. Para cada ponto, mede-se o erro: a distância vertical até a reta.
  3. O MSE é a média dos erros ao quadrado.
  4. O gradiente indica para onde mudar w e b para o erro cair. Cada passo é multiplicado pela taxa de aprendizado.
  5. Repetindo, a reta converge para a solução exata.
